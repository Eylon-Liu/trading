# Quant Research Terminal

Point-in-time equity research — screening, backtesting, filings intelligence
and policy tracking. Source: <https://github.com/Eylon-Liu/trading>

This is a **read-only demo** running on a point-in-time database snapshot of
the Dow 30. Screening, backtesting, comparison and filings intelligence all
work normally. Live data ingestion, report emailing and new AI generation are
disabled, because an unauthenticated page cannot responsibly spend the
deployer's API quota or send mail on request.

Clone the repository to run it without limits.
